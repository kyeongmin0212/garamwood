[ SNS / 채널 아이콘 이미지 넣는 곳 ]

이 폴더(icons)에 아래 파일명으로 아이콘 이미지를 저장한 뒤,
담당자에게 "넣었어"라고 알려주면 사이트의 모든 아이콘이
이 이미지로 연결됩니다.

필요한 파일 (정확히 이 이름으로 저장):

  instagram.png    ← 인스타그램      (상단 SNS 바 + 푸터)
  naver-blog.png   ← 네이버 블로그    (상단 SNS 바 + 푸터)
  youtube.png      ← 유튜브          (상단 SNS 바)
  naver-map.png    ← 네이버 지도      (상단 SNS 바 + 푸터)
  google-map.png   ← 구글 지도        (상단 SNS 바)
  kakaotalk.png    ← 카카오톡        (푸터)

권장 사양:
  - 형식: PNG (배경 투명 권장). JPG/SVG도 가능 — 다만 확장자가 위와 같아야 함
    (확장자가 .svg 등으로 다르면 담당자에게 알려주세요. HTML src를 맞춰 드립니다.)
  - 크기: 정사각형 (예: 64x64, 128x128). 화면엔 작게(18~20px) 표시됨
  - 같은 톤/스타일로 맞추면 더 깔끔함

※ 파일이 없으면 아이콘은 표시되지 않고 글자/빈칸만 나옵니다 (깨진 이미지 X).
